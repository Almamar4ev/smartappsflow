حزمة Smart Loan Calculator — الخطوات التالية
التاريخ: 24 يوليو 2026

============================================================
1) قبل دمج فرع التوحيد (chore/smartloan-consolidate)
============================================================

- افتح صفحة Actions في GitHub.
- شغّل "Build Smart Loan AAB" يدويًا على الفرع chore/smartloan-consolidate
  (Run workflow → اختر الفرع). لأن الحدث workflow_dispatch وليس pull_request،
  سيعمل التوقيع الكامل.
- تأكد من نجاح:
  npm test
  Android build
  Build Release AAB (موقّع)
  Build Debug APK
  Upload artifacts
- نزّل SmartLoanCalculator-debug-apk واختبره على هاتف.
- تأكد من ظهور SmartLoanCalculator-release-aab (موقّع).

لا تدمج إلى main قبل نجاح ما سبق. الدمج إلى main ينشر نسخة الويب فورًا للجمهور.

============================================================
2) بعد الدمج مباشرة — رابط سياسة الخصوصية
============================================================

انتقلت privacy-policy.html إلى داخل smartloan/، فتغيّر رابطها العام إلى:

  https://smartappsflow.net/smartloan/privacy-policy.html

- حدّث هذا الرابط في Google Play Console (App content → Privacy policy).
- افعل ذلك بعد الدمج والنشر فقط، وإلا يصبح الرابط معطّلًا مؤقتًا.

============================================================
3) طريقة العمل للتعديلات القادمة (نمط TradeLog Pro)
============================================================

كل مهمة مركّزة على فرعها الخاص، وتُدمج عبر Pull Request مستقل بعد نجاح Actions:

- إصلاح/تحسين حسابات أو واجهة:   fix/smartloan-<الوصف>
- تنظيف أو تنظيم:                 chore/smartloan-<الوصف>
- إعادة هيكلة (فصل CSS/JS):       refactor/smartloan-structure

قواعد ثابتة:
- لا تخلط مهمتين غير مرتبطتين في فرع واحد.
- لا تعمل إعادة الهيكلة في نفس فرع الإصلاحات.
- شغّل npm test قبل وبعد كل تغيير جوهري.
- لا تلمس التطبيقات الأخرى ولا الصفحة الرئيسية ولا CNAME.
- لا تشارك أسماء أسرار توقيع Smart Loan مع أي تطبيق آخر.
- بعد إنجاز أي مهمة، سجّلها في CHANGES_COMPLETED_AR.txt (طريقة الأرشفة).
