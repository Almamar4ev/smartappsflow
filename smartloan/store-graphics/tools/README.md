# أدوات صور متجر emiGo

هذه الأدوات تولّد صور Google Play من التطبيق الحقيقي. لا ترسم الشاشات: تفتح `index.html` في Chrome بأرقام تجريبية ثابتة، وتلتقط الشاشات بدقة 4×، ثم تركّبها بطابع صور المتجر: خلفية بنفسجية، وعنوان كبير، وإطار جوال، وبطاقة عائمة.

المخرجات: 7 صور لكل لغة (en وar) بمقاس 2160×3840 بنسبة 9:16، PNG بلا شفافية، وحوالي 2 ميجا للصورة.

## التشغيل (من هذا المجلد)

```bash
npm i playwright-core@1.49.1                 # مرة واحدة، يستخدم Chrome المثبت
(cd ../.. && python -m http.server 8765 --bind 127.0.0.1 &)   # يخدم مجلد التطبيق
node capture.js en && node capture.js ar      # لقطات خام في raw/<lang>/
node compose.js                               # الصور النهائية في out/
python prev.py                                # معاينات صغيرة p-*.png للمراجعة
```

- `node compose.js en2` يولّد صورة واحدة فقط، هنا الصورة الثانية بالإنجليزية.
- `APPURL=http://127.0.0.1:8766/index.html` يلتقط من خادم آخر، مثل worktree فيه تعديل لم يُدمج.
- `CHROME=...` يغيّر مسار Chrome.

## الملفات

| الملف | ماذا يفعل |
|---|---|
| `lib.js` | يفتح التطبيق، ويمسح التخزين، ويزرع البيانات التجريبية، ويخفي الجولة والتنبيهات |
| `capture.js` | يلتقط الشاشات كاملة، ويقص عناصر البطاقات العائمة، ويحقن خط Roboto وNoto Sans Arabic كهاتف أندرويد |
| `compose.js` | النصوص (`COPY`) والتخطيط والإطار وشريط الحالة. شريط الحالة معكوس في العربية |
| `prev.py` | يصغّر الصور للمراجعة |

## البيانات التجريبية (قرار المالك، 9 نوفمبر 2026)

- **الأرقام منطقية لفرد متوسط:** راتب 2,200$، ومصروفات ثابتة 700 ومتغيرة 300، وحد البنك 40% من الإجمالي.
- **قروضي:**
  - «سيارة / Car»: 9,000$، 5 سنوات، 5.9%.
  - «أثاث المنزل / Home furniture»: 4,000$، 3 سنوات، 7.5%.
- **الخطط:** «البنك أ/ب/ج»، قرض شخصي 12,000$:
  - البنك أ: 4 سنوات، 6.5%.
  - البنك ب: 5 سنوات، 6.2%.
  - البنك ج: 4 سنوات، 7%.
- **ممنوع:** قرض زواج، أو أسماء عائلية مثل «سيارة العائلة»، أو أرقام كبيرة غير واقعية.
- **العناوين لا تذكر عملة بعينها** (مثل «كل دولار»)، لأن التطبيق متعدد العملات حتى لو كانت أرقام الصور بالدولار.

## قبل التسليم

1. راجع المعاينات بعينك: لا نص مقطوع، والبطاقة العائمة في مكانها.
2. تأكد أن كل صورة 2160×3840 بنمط RGB، وأقل من 8 ميجا.
3. ضعها في `Downloads\emiGo-store-screenshots-<version>\{en,ar}`.
